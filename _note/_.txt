React chỉ chịu trách nhiệm:

Hiển thị checkbox, dropdown, input.
Thu thập lựa chọn người dùng.
Gửi PrintOptions.
Hiển thị trạng thái loading/error.
Render kết quả PDF.

Ví dụ:
{
  "showHeader": true,
  "showLogo": false,
  "includeDetails": true,
  "language": "vi"
}

.NET chịu trách nhiệm:

Lấy dữ liệu.
Quyết định layout.
Header/footer.
Pagination.
Table rendering.
Font.
Margin.
Page break.
Watermark.
Template version.
Export format.
